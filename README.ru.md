# Как скачать и запустить

1. На странице репозитория нажмите **Code → Download ZIP**.
2. Распакуйте архив в любую папку (лучше с коротким путём, например `C:\Case\`).
3. Установите Python 3.10+ (если его ещё нет) и дважды щёлкните **START.bat** (macOS/Linux — `./start.sh`). Node.js не нужен — интерфейс уже собран.
   > В публичной версии репозитория вшитое окружение `runtime/` не хранится — оно нужно только для офлайн-поставки заказчику.
4. Обновление: скачайте ZIP заново и замените папку, предварительно сохранив свои данные (загруженные файлы, папку `output/`), если вы их загружали.

# КОРПУС — ИИ-агенты для анализа результатов тестовых заданий

Проект конкурса кейсов для **Корпоративного университета Санкт-Петербурга**. Группа
ИИ-агентов автоматически анализирует результаты прохождения тестов слушателями
электронных курсов: сверяет ответы с эталоном, ищет критические вопросы и аномалии
времени/попыток, формирует структурированные отчёты и отвечает на вопросы методиста в
чате. Принцип системы — **«сначала код, ИИ в последнюю очередь»**: основные расчёты
детерминированы, обращения к нейросетям минимальны и настраиваемы.

---

## Быстрый запуск

- **Windows:** двойной клик по **`START.bat`**. Если в поставке есть папка `runtime\`
  (вшитый Python) — **ничего устанавливать не нужно**, даже Python. Иначе нужен
  установленный Python 3.10+.
- **macOS / Linux:** `./start.sh` (нужен Python 3.10+).

Node не требуется ни в одном случае — интерфейс уже собран.

Скрипт сам создаст окружение, поставит зависимости, поднимет веб-сервер и откроет
браузер. Подробности и запуск через CLI — в [`docs/run_guide.md`](docs/run_guide.md).
Краткая инструкция для методиста — [`docs/QUICKSTART.md`](docs/QUICKSTART.md).

---

## Возможности

- **Сравнение ответов** с эталоном (выбор/сопоставление/ранжирование — детерминированно;
  свободные текстовые ответы — с привлечением ИИ), оценка совпадения в процентах/баллах,
  выявление вопросов с массовыми ошибками («критические вопросы»).
- **Анализ попыток**: распределение баллов по тесту, аномалии паттернов попыток (число
  попыток, разброс баллов), доля брошенных. Полноценный тайминг по каждому вопросу в
  выгрузке LMS отсутствует — система прямо сообщает об этом; аномалии скорости
  подсвечиваются, когда данные о времени доступны.
- **Отчёты**: JSON (машиночитаемый), **Excel с цветной подсветкой отклонений**,
  текстовый отчёт; разрезы по курсу/группе.
- **Две группы нейросетей**: российская (**GigaChat**) и зарубежная (**OpenRouter**),
  переключаются в настройках.
- **Чат-агент**: отвечает на вопросы строго по данным анализа, строит динамику, сравнивает
  прогоны, по подтверждению запускает новый анализ, собирает готовый отчёт.
- **Форматы входа**: `.xlsx`, `.json`, `.csv`, отдельный файл или папка
  ([`docs/input_formats.md`](docs/input_formats.md)).
- **Запуск**: веб-интерфейс и командная строка (`main.py`).

## Архитектура (кратко)

```
            вход (.xlsx / .json / .csv / папка)
                          │
              pipeline.data_loader  →  CourseData (+ validate)
                          │
          ┌───────────────┴───────────────┐
          ▼                               ▼
   answer_agent                      time_agent
 (сверка с эталоном,            (медианы, аномалии
  критические вопросы)           времени и попыток)
          └───────────────┬───────────────┘
                          ▼
      report_agent  +  insight_agent (ИИ-выводы)
                          │
        отчёты: JSON · Excel(подсветка) · текст · history
                          │
      web (FastAPI + React SPA)  /  chat_agent  /  CLI
```

Три анализирующих агента (`answer_agent`, `time_agent`, `report_agent`) плюс
`insight_agent` (ИИ-комментарии) и `chat_agent` (диалоговый помощник). Веб-слой —
FastAPI + React-SPA. Полное описание — [`docs/developer_guide.md`](docs/developer_guide.md).

## Структура репозитория

```
agents/        ИИ-агенты: answer_agent, time_agent, report_agent, insight_agent, chat_agent
pipeline/      загрузка/парсинг данных (data_loader, parsers), оркестрация (runner), статистика
core/          конфигурация, настройки, доменные модели, история прогонов
models/        адаптеры провайдеров (OpenRouter / GigaChat), выбор клиента
web/           FastAPI: app.py (v0.1), api.py (JSON-API), serve.py (прод: SPA+API), frontend/ (React)
data/          samples/ + etalon/ (примеры .xlsx), samples_jsoncsv/ (примеры JSON/CSV)
docs/          документация (см. ниже)
scripts/       launch.py — bootstrap для START.bat / start.sh
config.yaml    модели, пороги, бюджеты (без секретов)   .env.example  шаблон ключей
main.py        CLI    requirements.txt    START.bat / start.sh
```

## Соответствие требованиям кейса

| Требование | Где реализовано |
|---|---|
| Сравнение ответов с эталоном, оценка совпадения | `agents/answer_agent`, `pipeline/parsers` |
| Анализ времени, аномалии, сравнение с медианой | `agents/time_agent` |
| Отчёт с критическими изменениями и рекомендациями | `agents/report_agent`, `agents/insight_agent` |
| Две группы агентов (РФ + зарубеж) | `models/`, `config.yaml` |
| Форматы входа: JSON, CSV, папки | `pipeline/data_loader`, `pipeline/parsers`, [`docs/input_formats.md`](docs/input_formats.md) |
| Форма отчёта: JSON, Excel с подсветкой | `agents/report_agent/excel_generator.py`, `web/app.py` (`/download`) |
| Запуск: CLI или веб | `main.py`, `web/serve.py`, `START.bat` |
| Обработка некорректных данных | `CourseData.validate()`, обёртки парсеров (ошибка → предупреждение) |
| Проектная документация | `docs/` (пользователь, администратор, разработчик) |

## Технологии

**Backend:** Python 3.12, FastAPI, uvicorn, pydantic v2, openpyxl, rapidfuzz, openai
(OpenRouter), gigachat. **Frontend:** React 18, Vite, TypeScript, TailwindCSS, Recharts.
**Тесты:** pytest (backend), vitest (frontend).

```bash
# backend
.venv/Scripts/python -m pytest
# frontend
cd web/frontend && npm test
```

Ключи нейросетей и пороги задаются в `.env` и `config.yaml` — в коде ничего не
захардкожено.
