# КОРПУС — краткая инструкция

Одна страница, чтобы запустить программу и получить первый результат. Подробности —
в `docs/user_guide.md`; вопросы установки — в `docs/run_guide.md`.

---

## 1. Запустить программу

- **Windows:** двойной клик по **`START.bat`** в папке с решением.
- **macOS / Linux:** `./start.sh` в терминале из той же папки.

Первый запуск длится 1–3 минуты (один раз ставятся компоненты, нужен интернет). Когда
всё готово, браузер откроется сам на странице программы. Ничего настраивать не нужно:
базовый анализ работает без ключей и интернета.

---

## 2. Сделать анализ за 3 шага

1. **Загрузите файлы.** Вкладка **«Новый анализ»** → перетащите выгрузку результатов
   из СДО (`.xlsx`) в карточку **«Ответы пользователей»**, а файл-ключ с правильными
   ответами — в карточку **«Эталонные ответы»**. Нажмите **«Запустить анализ»**.
   - Несколько файлов ответов = несколько групп в одном анализе.
   - Параметры (модель, **«Глубокий анализ с ИИ»**, лимит обращений) заданы в **«Настройках»**;
     под кнопкой видно, что будет использовано.
2. **Посмотрите результат.** Откроется вкладка **«Результаты»**: ключевые метрики,
   таблица **критических вопросов** (где курс проваливают), ИИ-выводы и анализ попыток.
3. **Спросите агента или скачайте отчёт.** Кнопка **«Уточнить у агента»** открывает чат
   по этому анализу; **«Скачать Word»** и **«Скачать PDF»** сохраняют готовый отчёт.

---

## 3. Что ещё умеет программа

| Хочу… | Куда идти |
|---|---|
| Сравнить два анализа (что изменилось) | вкладка **«Сравнение»** или «История» → отметить два |
| Найти прошлый анализ, скачать Word / PDF / Excel | вкладка **«История»** |
| Задать вопрос по данным простым языком | вкладка **«Чат с агентом»** |
| Получить файл-отчёт (Word / PDF) | кнопки вверху вкладки **«Результаты»** |
| Параметры анализа, российские/зарубежные модели, ключи | **«Настройки»** (шестерёнка) |

---

## Полезно знать

- **Критический вопрос** — вопрос с низкой долей правильных ответов; именно с них стоит
  начинать актуализацию курса.
- **Все числа в чате берутся из отчёта**, а не выдумываются ИИ. Источник можно проверить
  в блоке **«Ход рассуждений»** под ответом агента.
- **Эталон желателен:** задания с выбором проверяются и без него, а свободные текстовые
  ответы корректно оценить можно только с файлом-ключом.

Полное руководство со всеми вкладками и метриками — `docs/user_guide.md`.
